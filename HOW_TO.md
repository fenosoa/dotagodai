# Comment utiliser

## 1. Installer (une seule fois)

```bash
npm install
```

## 2. Démarrer

```bash
npm start
```

## 3. Ouvrir la page

http://localhost:3000/farming.html

## 4. Visualiser un trajet

Glissez-déposez un fichier replay **.dem** sur la carte, puis cliquez sur le
joueur à analyser. Le trajet s'affiche automatiquement.

(Vous pouvez aussi déposer directement un fichier **.json** déjà généré si
vous en avez un.)

C'est tout.
